# Syntrax Technologies Website

Premium enterprise website for **Syntrax Technologies** — cybersecurity, software, infrastructure and digital solutions for East African institutions and businesses.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- CMS-ready content modules in `src/content`

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — lint

## Content

Editable content lives in:

- `src/content/site.ts`
- `src/content/services.ts`
- `src/content/products.ts`
- `src/content/industries.ts`
- `src/content/insights.ts`
- `src/content/faqs.ts`
- `src/content/navigation.ts`

Official contact details and live product URLs are configured in `src/content/site.ts`.

## Notes

- No invented clients, statistics, partnerships or testimonials are published.
- Case studies, team and partners sections are structured and can be enabled when approved content exists.
- Forms validate on the server and are ready to connect to email/CRM/ticketing backends.
- English is default; Swahili architecture is prepared in `src/i18n`.
